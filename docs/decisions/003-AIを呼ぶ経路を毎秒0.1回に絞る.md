# 003 — AIを呼ぶ経路を毎秒0.1回に絞る

LLMを呼ぶ経路（初版は `POST /search`）をAPI Gatewayのルート別スロットリングで毎秒0.1回程度に絞る。

## 理由

制限しなければ、毎秒1回で張り付かれるだけで1日 $38（月 $1,140）になる。毎秒0.1回に絞ると1日 $3.80（月 $114）で止まる。この10倍の差が判断の理由である。計算の内訳は [cost.md](../cost.md) にある。

AWSには支出の強制的な上限が原則としてなく、AWS Budgetsは反映が数時間から半日遅れるため、事後の検知では止められない。事前のレート制限だけが最悪額を固定できる。

## あわせて入れるもの

- LLMの日次カウンタ（1日300回程度で429を返す。普段の利用を守る柔らかい上限）
- Lambdaの同時実行数を2〜5に固定（0にすれば全停止できる）
- CloudWatch Logsの保持期間7日
- robots.txtで巡回を断る
- 応答はJSONだけを返し、画像はS3とCloudFrontから配信する（大量に叩かれたとき、課金の支配項が転送量になりやすいため応答を小さく保つ）

## 未確認の事項

API Gatewayのルート別スロットリングで毎秒1回未満の値が実際に効くかは未検証。効かない場合は毎秒1回に上げ、日次カウンタを硬い上限として扱う（その場合の最悪額は1日約 $38）。

## トレードオフ

- 正当な利用者が同時に集中しても毎秒0.1回しか通らない。PoCの利用量（1日100〜300回）では問題にならない。
