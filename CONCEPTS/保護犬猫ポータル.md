# 保護犬猫ポータル — 仕様

更新日: 2026-08-19

全国の保護犬猫の譲渡情報を、1か所で検索できるようにする Web サービスです。掲載元は自治体の収容動物公示と、愛護団体が公開しているページです。団体ごとにばらばらなサイトで掲載されている現状を、集約検索と元サイトへの送客で補います。

## 位置づけと目的

- 収益化を目的にしません。公開して実際に使われることと、「分散データの集約基盤」を他の題材へ再利用できる形で作ることを狙います。
- 器は全国対応で作ります。ただし掲載の密度が価値なので、まず1県に絞って充実させます。対象県は未定です。

## できること

利用者向け:

1. **検索** — 「小型で子どもと暮らせる犬」のような自由文で探せます。AI が問い合わせ文から種別・地域・条件を読み取り、候補を確からしい順に返します。
2. **詳細と送客** — 詳細画面は要点と出典を示し、譲渡の申込みは必ず元サイトへ誘導します。
3. **新着通知** — 検索条件を保存しておくと、合致する子が載ったときに LINE で通知します。

団体向け（オプトイン）:

4. **登録** — 写真と自由文メモを送るだけで掲載できます。AI が「種別・推定年齢・性格・譲渡条件」などを構造化する処理は、登録操作の裏で非同期に行います。
5. **掲載管理** — 自分の掲載を一覧・編集できる管理画面を持ちます。
6. **埋め込みウィジェット** — 団体の既存ホームページへ、1行のタグで自分の掲載一覧を埋め込めます。

画面はスマートフォンと PC の両方に対応したレスポンシブな Web です。

## データの三層

| 層 | 掲載元 | 扱い |
|---|---|---|
| 1 | 環境省・自治体の収容動物公示 | 出典明記のうえ全文と写真を掲載する。政府標準利用規約など、転載が許諾されるものだけを使う |
| 2 | 愛護団体の公開ページ | 構造化した事実データ、短い抜粋、小さいサムネイル、元サイトへのリンクに限定する |
| 3 | オプトイン登録した団体 | 写真を含むリッチ表示。写真・文章の利用許諾はこの登録時に取得する |

- 第2層は著作権法47条の5（所在検索サービスの軽微利用）の範囲に収める設計とし、公開前に弁護士へ確認します。
- クロールは robots.txt の尊重、低頻度アクセス、連絡先の明示、オプトアウト窓口を必須とします。
- 第2層の団体が第3層へ移る動機は、表示の差（リンクのみ か リッチ表示か）で作ります。移行の営業はしません。

## 技術構成

フロントエンドは React + Vite + TypeScript で作り、S3 + CloudFront から配信します。集客の本体は検索エンジン経由の流入なので、「地域×条件」の一覧ページは静的生成して配信します。LINE は検索の入口としては補助で、新着通知を主な役割とします。

データ収集は「クローラ → SQS → Lambda で AI 構造化 → PostgreSQL」のパイプラインにします。団体のオプトイン登録も同じ構造化経路に載せます。API は API Gateway + Lambda、団体ログインは Amazon Cognito です。

データベースは PostgreSQL です。置き場所は Aurora Serverless v2（Aurora Data API）と、無料枠のあるマネージド PostgreSQL（Neon など）の二択で、まだ決めていません。開発中はローカルの Docker で PostgreSQL を動かすため、この決定はクラウドへ載せるときまで先送りできます。検索は PostgreSQL の全文検索とあいまい一致（pg_trgm 拡張）で行い、Embedding とベクトル類似度検索は使いません。全国でも掲載は数万件規模で、この方式で足ります。

AI（LLM）には Amazon Bedrock 上の GPT-5.6 Luna を使います。LINE 連携は LINE Messaging API の Webhook を Lambda で受けます。実装言語は TypeScript を主とし、必要な箇所では Python も使います。

各機能は共通ルールに従い、まず CLI として実装してから Web UI をその上へ重ねます。クローラ・構造化・検索を CLI で通すことが最初の縦切りです。

## 費用

無料枠に収まる構成を基本とします。

- データベースは Neon を選べば無料枠（ストレージ 0.5GB、月 100 CU 時間、5分無操作で自動停止）に収まる見込みです。テキスト主体の数万件はこの範囲です。
- 写真の保存（S3）は第1層とオプトイン登録の分だけとし、第2層はサムネイルのみ保持します。
- LLM 費用は従量です。構造化は1件500トークン程度なので、数万件の初回処理でも $1 未満、差分更新と検索応答を合わせて月数ドルの見込みです。
- LINE の push 通知は無料枠（月200通）から始めます。超える場合は費用を確認してから有料プランを判断します。

## 決めていないこと

- 掲載密度を作る対象県
- サービス名とドメイン
- データベースの置き場所（Aurora か Neon か）
- 弁護士確認の依頼先と時期（公開前に必須）
